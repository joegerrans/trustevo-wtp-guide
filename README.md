# The Wealth Turning Point

Guide site for https://wealth-turning-point.trustevo.co.uk/.

## Updating the guide PDF

Replace the PDF in this repository. If the filename stays the same, nothing else needs to change.

If the filename changes, update the `/pdf` redirect destination in `vercel.json`.

Then push to `main`. This site auto-deploys from `main`.

The permanent link is https://wealth-turning-point.trustevo.co.uk/pdf. Never link to the PDF filename, and do not add a `?v=` query string.
